# Лабораторная работа № 2. Java Reflection — генератор объектов

@Generatable ставится на предпочтительный конструктор. Предпочтительный конструктор может быть только один, это проверяет Annotation processor. Предпочтительнее конструктор без параметров с рекурсивным типом, если таких нет, то параметры рекурсивного типа получают `null`. Для интерфейса или абстрактного класса генератор ищет конкретную реализацию в том же пакете, аннотацию следует ставить на конструктор найденной реализации.

Генератор поддерживает примитивы, обёртки, строки, enum, одномерные массивы, `List` как `ArrayList`, `Map` как `HashMap` и пользовательские классы; для параметризованных конструкторов поддерживаются generic аргументы, заданные конкретным классом. Рекурсия ограничена глубиной, а повторное появление класса даёт `null`.
